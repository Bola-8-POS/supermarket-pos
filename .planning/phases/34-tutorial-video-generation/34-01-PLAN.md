<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tutorial harness -> local Supabase | `locale.ts`'s `seedStaffLocale()` writes `profiles.locale` via the service-role client, same trust boundary every other `e2e/helpers/supabase.ts` setter already crosses |
| Recorded video -> filesystem | Frames/captions rendered by the real app run inside a Playwright-driven Chromium tab; nothing server-side is exposed by recording |
| Tutorial harness -> CI-critical suite | A misconfigured `testIgnore` would let `e2e/tutorials/**` run inside `npm run test:e2e` |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
